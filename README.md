# e-zines

flip-through zines by raine sillito · the luminarium. read them in the browser, type into the pages, then print the paper version.

- `found-poetry/` — how to write found poetry
- `rainy-day/` — instructions for a rainy day

plain html, css and js. no build step. fonts and art live in `assets/`. whatever you type is saved only in your own browser.
